# Rasson Snooker Academy — Scoring App

Professional-mode customer scoring application for Rasson Snooker Academy.

## Current foundation

- Mobile-first dark luxury Rasson UI
- Player 1 / Player 2 setup
- Frame scoreboard
- Red/colour scoring flow
- Foul scoring
- Turn switching
- Break history
- New frame / reset match controls

## Next rules-engine phase

The current repository is the UI foundation. Before live deployment, the full snooker event log should be added for accurate undo, break tracking, fouls, end-of-frame colours, frame result detection, and persistent match history.

## Run

Open `index.html` in a browser, or deploy the repository as a static site on Vercel/GitHub Pages.
